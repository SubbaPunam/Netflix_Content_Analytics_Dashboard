1.Project Title
Netflix Content Analytics Dashboard

2.Short Description
An interactive Power BI dashboard designed to analyze Netflix content, including movies, TV shows, genres, ratings, countries, and release trends through KPIs and data visualizations.

3.Tech Stack
Microsoft Power BI
Power Query
DAX (Data Analysis Expressions)

4.Data Source
Netflix Movies and TV Shows dataset downloaded from Kaggle in CSV format.

5.Features
KPI Cards: Display total titles, movies, TV shows, countries, and average release year.
Movies vs. TV Shows: Compare the distribution of movies and TV shows.
Content Added Over Time: Analyze trends in Netflix content additions.
Top 10 Genres: Identify the most common genres on Netflix.
Top 10 Countries: Explore countries with the highest number of titles.
Ratings Distribution: Analyze content distribution by rating.
Movies vs. TV Shows by Year: Compare movie and TV show release trends over time.
Interactive Slicers: Filter content by type, rating, release year, and country
